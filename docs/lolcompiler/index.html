lolcompiler: compiles a LOLCODE Markdown (.lol) file into HTML.

Usage: lolcompiler input.lol

Steps:

  1. Check there is one argument and that it ends in .lol.
  2. Read the file and run the compiler (lexer -> parser -> scope check -> HTML). Any error is printed and the program exits before any file is written.
  3. Write input.html next to the input file and open it in the default browser.
